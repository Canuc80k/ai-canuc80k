## Ba nhóm phép biến đổi

**Hình học**: lật, crop, xoay, dời → áp cả lên box, mask, điểm mốc.

**Cường độ**: sáng, tương phản, màu, nhiễu → giữ vị trí, có thể đụng tín hiệu nhãn.

|||

**Che và trộn**: Cutout giữ nhãn.

Mixup: $\tilde x=\lambda x_i+(1-\lambda)x_j$,

nhãn $\tilde y=\lambda y_i+(1-\lambda)y_j$.

CutMix: trộn nhãn theo diện tích.

## Tính tay lật box

Tọa độ theo biên: vùng ngang là $[x_1,x_2)$, không gồm pixel ở $x_2$.

$$[x_1,x_2]\to[W-x_2,\ W-x_1]$$

$W=10$: $[1,4]\to[6,9]$.

---
## Kiểm box và mask cùng biến đổi

Trích khối code của bài: `mask` $4\times10$ sáng ở hàng 1–2, cột 1–3. Đoạn dưới kiểm cả tọa độ lẫn số pixel foreground.

```python
box = np.array([1, 1, 4, 3])
flipped_mask = np.flip(mask, axis=1).copy()
flipped_box = flip_box_xyxy(box, mask.shape[1])
print(flipped_box.tolist())
print(np.flatnonzero(flipped_mask[1]).tolist())
print(int(mask.sum()), int(flipped_mask.sum()))
```

```output
[6, 1, 9, 3]
[6, 7, 8]
6 6
```

## Encoder và head

Encoder tạo vector hoặc feature map.

Head học nhãn của nhiệm vụ hiện tại.

|||

Đóng băng encoder: feature extraction.

Mở block cuối hoặc toàn mạng: fine-tuning.

Cơ chế freeze, BatchNorm, optimizer: bài 4.3.

---
## Chọn điểm xuất phát

| | Miền gần nguồn | Miền xa nguồn |
|---|---|---|
| Ít ảnh | Feature extraction | Block giữa, mở dần |
| Nhiều ảnh | Mở block cuối, rate nhỏ | Mở nhiều; so với từ đầu |

Block đầu (cạnh, vân) dùng lại được; block sau gắn với vật thể nguồn.

## Ảnh xám vào encoder RGB

$$\sum_{c=1}^{3} W_c * x=\Big(\sum_{c=1}^{3} W_c\Big) * x$$

Chép kênh xám ba lần ≡ conv một kênh với weight **tổng**.

ResNet-18 conv đầu: $9408\to3136$ số.

---

![Ảnh xám chép thành ba kênh cho cùng đầu ra với conv một kênh có weight là tổng ba lát.](../fig/5-3-gray.svg)

## Kiểm trên bốn ảnh chữ số

```python
conv_gray.weight.copy_(
    conv_rgb.weight.sum(dim=1, keepdim=True))
out_repeat = conv_rgb(gray.repeat(1, 3, 1, 1))
out_folded = conv_gray(gray)
```

```output
weight: (8, 3, 3, 3) -> (8, 1, 3, 3)
output: (4, 8, 8, 8) (4, 8, 8, 8)
same output: True
```

|||

Hợp đồng đầu vào: số kênh, mean/std theo kênh, kích thước.

Ảnh $28\times28$ còn $1\times1$ ở block cuối; phóng lên 224 tốn gấp 64 lần.

- [x] Phần trước bias nhỏ đi 3 lần, các tầng sau nhận sai thang

Chép kênh tương đương với tổng ba lát weight. Trung bình bằng tổng chia 3, nên $W*x$ nhỏ đi 3 lần, và ReLU hay BatchNorm ở eval đều không bù lại.

## Khi đi thi

- Đọc luật: cấm pretrained hay được cấp checkpoint.
- Lưu grid ảnh sau augmentation kèm nhãn.
- Validation chia theo nguồn, mô phỏng điều kiện chấm.
- Feature extraction làm mốc, rồi mới fine-tune.
- TTA nhân thời gian forward: đo trước khi chọn.
