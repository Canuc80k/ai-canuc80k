## Thụt lề thay cho dấu ngoặc

```python
def passed_scores(values, threshold=5.0):
    result = []
    for value in values:
        if value >= threshold:
            result.append(value)
    return result
```

|||

- Dấu `:` mở một khối.
- Các dòng trong cùng khối thụt lề như nhau.
- `return` ở ngoài `for`: thu đủ phần tử rồi trả về.
- `range(1, 5)` lấy 1, 2, 3, 4.

## Chia số âm: khác C++

```python
print(7 / 2, 6 / 2)
print(7 // 2, -7 // 2)
print(7 % 3, -7 % 3)
```


|||

`//` làm tròn xuống. Với $b\ne0$:

$$a=(a//b)\cdot b+(a\%b).$$

`int` tăng độ chính xác theo nhu cầu; vẫn tốn thời gian và bộ nhớ khi số rất lớn.

## Chọn cấu trúc như khi thi lập trình

| Công việc | Cấu trúc |
|---|---|
| Giữ thứ tự, lấy bằng vị trí | `list` |
| Một bộ giá trị cố định | `tuple` |
| Tra cứu theo khóa | `dict` |
| Kiểm thuộc tập nhiều lần | `set` |

|||

`x in list`: $O(n)$ ở trường hợp xấu.

`x in set`: trung bình $O(1)$; tính cả chi phí dựng set.

Khóa cần **hashable** (có thể băm ổn định). `(3, 4)` được; tuple chứa list thì không.

## Tham số mặc định được tạo một lần

```python
def add_score(x, history=[]):
    history.append(x)
    return history

print(add_score(1), add_score(2))
```

```output
[1, 2] [1, 2]
```

|||

Hai lần gọi dùng chung list mặc định.

```python
def add_score(x, history=None):
    if history is None:
        history = []
    history.append(x)
    return history
```

## CSV phải được đọc lại

Giả sử `csv` đã được import, `path` là đường dẫn file cần ghi và `preds` là dict ánh xạ ID → dự đoán.

```python
with path.open(
    "w", newline="", encoding="utf-8"
) as file:
    writer = csv.writer(file)
    writer.writerow(["id", "prediction"])
    for student_id, prediction in preds.items():
        writer.writerow(
            [student_id, prediction]
        )
```

|||

- `with` đóng file khi ra khỏi khối.
- `encoding` và `newline` ghi rõ.
- Sau khi ghi, mở lại bằng `csv.reader` và kiểm header/số dòng.
- `csv.reader` đọc ô thành chuỗi; đổi kiểu trước khi tính.
- Module CSV xử lý cả dấu phẩy trong ô có ngoặc kép.
