Buổi 6.1: Audio data và spectrograms

Nếu đọc nhầm sample rate, âm thanh có còn đúng thời gian?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • Waveform có samples theo thời gian; sample_rate quyết định duration/frequency.
  • STFT chiaframes; Mel filters biến đổi phổ; padding cần mask.
  • Spectrogramtensor của IOAI Speech không phảiWAVraw.

duration=n_samples/sample_rate

Code minh họa

import numpy as np
# Tone tổng hợp 440Hz: để hiểu waveform và sample rate, không giọng thật.
sample_rate=8000; duration=.1
t=np.arange(int(sample_rate*duration))/sample_rate
wave=np.sin(2*np.pi*440*t)
window=np.hanning(len(wave))
spectrum=np.abs(np.fft.rfft(wave*window))
frequencies=np.fft.rfftfreq(len(wave),d=1/sample_rate)
peak=frequencies[spectrum.argmax()]
print("Samples:",len(wave),"duration:",len(wave)/sample_rate)
print("Peak frequency:",peak)
assert peak==440
# FFT phổ này chưa phải Mel spectrogram: cần nhiều frames và Mel filter bank.

Kết quả

Samples: 800 duration: 0.1
Peak frequency: 440.0

FFT mộtframe chưa phải Mel spectrogram đầyđủ.

Bài trên lớp

Bài 1

Trả n_samples/sample_rate seconds và frame count floor((n-window)/hop)+1 nếun>=window, khôngpad.

{
  "n_samples": 16000,
  "sample_rate": 16000,
  "window": 400,
  "hop": 160
}
Đáp án
{
  "seconds": 1.0,
  "frames": 98
}

Bài 2

DFTpowerchỉbinsk=0..floor(n/2), chọn max, tiesk nhỏ. Trảbin vàfreq=k*sample_rate/n.

{
  "wave": [
    0,
    1,
    0,
    -1
  ],
  "sample_rate": 4
}
Đáp án
{
  "bin": 1,
  "frequency": 1.0
}
