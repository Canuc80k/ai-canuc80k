BUỔI 1.1 — Học máy và quy trình làm bài

HỌC SINH CẦN HIỂU
- Một mẫu là một đối tượng/quan sát; feature mô tả; target là đáp án cần dự đoán.
- fit học từ dữ liệu có nhãn; predict nhận dữ liệu mới không có đáp án.
- Baseline đơn giản tạo mốc so sánh trước khi thử model phức tạp.

CÂU HỎI MỞ BÀI
Model là thuật toán hay là kết quả sau khi học?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
X:(n,d), y:(n,), predictions:(m,)

CẦN PHÂN BIỆT
Cột target hoặc thông tin chỉ có sau sự kiện không được nằm trong X.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Tách target khỏi records, giữ features theo danh sách tên cột đã cấp.
Input:
{
  "rows": [
    {
      "x": 2,
      "y": 5
    },
    {
      "x": 3,
      "y": 7
    }
  ],
  "features": [
    "x"
  ],
  "target": "y"
}
Output để đối chiếu sau khi làm:
{
  "X": [
    [
      2
    ],
    [
      3
    ]
  ],
  "y": [
    5,
    7
  ]
}

Bài trên lớp 2: Dự đoán lớp phổ biến; hòa thì chọn integer nhỏ nhất.
Input:
{
  "labels": [
    0,
    1,
    0,
    1
  ],
  "n_new": 3
}
Output để đối chiếu sau khi làm:
[
  0,
  0,
  0
]

BÀI VỀ NHÀ
- BTVN 1: Tách target khỏi records, giữ features theo danh sách tên cột đã cấp.; xem BTVN_01.txt.
- BTVN 2: Dự đoán lớp phổ biến; hòa thì chọn integer nhỏ nhất.; xem BTVN_02.txt.
- BTVN 3: Ghép predictions vào IDs theo khóa, không theo thứ tự dòng.; xem BTVN_03.txt.
