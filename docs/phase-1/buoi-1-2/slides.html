Buổi 1.2: Generalization, underfitting và overfitting

Train 100% có phải chắc chắn thi tốt hơn train 90%?

Buổi 1.2

Ý tưởng chính

gap = train_score - validation_score

  • Generalization là hiệu quả trên mẫu mới của mục tiêu thực tế.
  • Underfit: chưa học đủ quan hệ; overfit: học cả chi tiết/noise của train.
  • So capacity trên cùng split và metric; một split nhỏ có thể nhiễu.

Buổi 1.2

Code minh họa (1)

from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier

# Cùng dữ liệu và split như ví dụ của thầy; đây là dữ liệu tổng hợp.
X,y = make_moons(n_samples=80, noise=0.35, random_state=42)
Xtr,Xva,ytr,yva = train_test_split(X,y,test_size=0.35,
                                 stratify=y,random_state=27)
print("depth | train_accuracy | valid_accuracy")
results = []
for depth in [1,3,10,None]:
    model = DecisionTreeClassifier(max_depth=depth,random_state=42)
    model.fit(Xtr,ytr)
    train_score = model.score(Xtr,ytr)
    valid_score = model.score(Xva,yva)
