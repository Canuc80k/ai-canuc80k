BTVN 2 — Xác suất và thống kê dùng trong AI: conditional_precision
Mã local: aicanuc80kp1b08h2

YÊU CẦU
Từ TN, FP, FN, TP tính P(positive thật|báo positive); denominator bằng 0 trả 0.

INPUT
Đọc đúng một JSON object từ stdin.
tn/fp/fn/tp: nonnegative integers.
Trừ giới hạn riêng ở trên: list 1D tối đa 1000 phần tử; ma trận tối đa 100 hàng, 64 cột; |số thực|<=1e6. Các ma trận hình chữ nhật và kích thước tương thích. Không có dữ liệu sai schema.

OUTPUT
In đúng một JSON value chứa kết quả yêu cầu, không thêm dòng giải thích. Thứ tự list giữ theo quy định; dict không yêu cầu thứ tự keys. Sai số số thực được chấp nhận: abs_error <=1e-6+1e-6*abs(expected). Booleans khác numbers.

VÍ DỤ INPUT
{
  "tn": 72,
  "fp": 8,
  "fn": 2,
  "tp": 18
}

VÍ DỤ OUTPUT
0.6923076923076923

GIẢI THÍCH VÍ DỤ
Áp dụng yêu cầu lên chính input đã cấp. Với dữ liệu của lớp, không tự đổi positive class, quy ước tie, axes hoặc denominator.

CẦN NỘP
Một chương trình đọc stdin/in stdout và code đã dùng. Có thể dùng json,math,collections; ở bài primitive này không gọi một model/thư viện đã làm sẵn toàn bộ phép toán cần cài.

TỰ KIỂM TRA
- Chạy input mẫu và so semantic JSON với output mẫu.
- Kiểm trường hợp biên đã nêu trong yêu cầu, không thêm giả định ngoài đề.
- Không dùng print debug trong output nộp.
