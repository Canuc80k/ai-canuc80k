BUỔI 1.8 — Xác suất và thống kê dùng trong AI

HỌC SINH CẦN HIỂU
- Mean dễ bị outlier kéo; median mô tả vị trí giữa khi sắp thứ tự.
- Variance/std mô tả độ phân tán; phải phân biệt population/sample convention.
- Xác suất có điều kiện phụ thuộc mẫu số; nhãn quyết định không phải probability.

CÂU HỎI MỞ BÀI
P(cảnh báo|lỗi) có bằng P(lỗi|cảnh báo) không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
P(lỗi|cảnh báo) = TP/(TP+FP)

CẦN PHÂN BIỆT
Đảo điều kiện thay đổi mẫu số và ý nghĩa.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Trả mean, population variance; phân biệt generator collapse với cùng mean.
Input:
{
  "values": [
    1,
    2,
    3
  ]
}
Output để đối chiếu sau khi làm:
{
  "mean": 2.0,
  "variance": 0.6666666666666666
}

Bài trên lớp 2: Từ TN, FP, FN, TP tính P(positive thật|báo positive); denominator bằng 0 trả 0.
Input:
{
  "tn": 72,
  "fp": 8,
  "fn": 2,
  "tp": 18
}
Output để đối chiếu sau khi làm:
0.6923076923076923

BÀI VỀ NHÀ
- BTVN 1: Trả mean, population variance; phân biệt generator collapse với cùng mean.; xem BTVN_01.txt.
- BTVN 2: Từ TN, FP, FN, TP tính P(positive thật|báo positive); denominator bằng 0 trả 0.; xem BTVN_02.txt.
- BTVN 3: Binary log loss trung bình, dùng natural log; prob0/1 clip vào[1e-12,1-1e-12].; xem BTVN_03.txt.
