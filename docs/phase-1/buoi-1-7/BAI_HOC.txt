BUỔI 1.7 — Đại số tuyến tính dùng trong AI

HỌC SINH CẦN HIỂU
- Mỗi hàng của X là feature vector; dot product kết hợp các features bằng weights.
- Matrix multiplication yêu cầu chiều trong khớp nhau.
- Euclidean/cosine là hai cách đo khác nhau; cosine bỏ qua độ lớn sau normalize.

CÂU HỎI MỞ BÀI
X@w tạo một kết quả cho mỗi mẫu bằng cách nào?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
ŷ = Xw + b

CẦN PHÂN BIỆT
Cosine trực tiếp không xác định cho vector0; đề cần quy ước rõ.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Tính matrix@vector; số cột bằng chiều dài vector.
Input:
{
  "matrix": [
    [
      1,
      2
    ],
    [
      3,
      4
    ]
  ],
  "vector": [
    2,
    -1
  ]
}
Output để đối chiếu sau khi làm:
[
  0,
  2
]

Bài trên lớp 2: Chuyển vị ma trận: output[j][i]=input[i][j].
Input:
{
  "matrix": [
    [
      1,
      2,
      3
    ],
    [
      4,
      5,
      6
    ]
  ]
}
Output để đối chiếu sau khi làm:
[
  [
    1,
    4
  ],
  [
    2,
    5
  ],
  [
    3,
    6
  ]
]
