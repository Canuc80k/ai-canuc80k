BUỔI 1.5 — Đánh giá classification

HỌC SINH CẦN HIỂU
- Chốt positive class trước khi tính TP, FP, FN, TN.
- Precision quan tâm báo nhầm; recall quan tâm bỏ sót; F1 kết hợp hai đại lượng.
- AUC dùng scores/probabilities; threshold thay đổi labels và F1.

CÂU HỎI MỞ BÀI
Báo động giả và bỏ sót nên phạt giống nhau không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
F1 = 2TP / (2TP + FP + FN)

CẦN PHÂN BIỆT
Binary F1, macro F1 và weighted F1 không thay thế tùy tiện cho nhau.

THỰC HÀNH TRÊN LỚP

  "pred": [

Output để đối chiếu sau khi làm:
[
  1,
  1,
  1,
  1

Input:
{

    1,

    0,
    0
  ],
  "pred": [
    1,
    0,
    1,
    0
