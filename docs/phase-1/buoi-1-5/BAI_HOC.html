Buổi 1.5: Đánh giá classification

Báo động giả và bỏ sót nên phạt giống nhau không?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • Chốt positive class trước khi tính TP, FP, FN, TN.
  • Precision quan tâm báo nhầm; recall quan tâm bỏ sót; F1 kết hợp hai đại lượng.
  • AUC dùng scores/probabilities; threshold thay đổi labels và F1.

F1 = 2TP / (2TP + FP + FN)

Code minh họa

from sklearn.metrics import confusion_matrix,precision_score,recall_score,f1_score,roc_auc_score
# Positive=1; xác suất dùng cho AUC, nhãn dùng cho F1.
y = [1,1,0,0]
prob = [0.9,0.4,0.6,0.1]
pred = [int(p>=0.5) for p in prob]
print("pred:",pred)
print("Confusion [TN FP; FN TP]:",confusion_matrix(y,pred).tolist())
print("Precision:",precision_score(y,pred,zero_division=0))
print("Recall:",recall_score(y,pred,zero_division=0))
print("F1:",f1_score(y,pred,zero_division=0))
print("ROC AUC:",roc_auc_score(y,prob))
assert f1_score(y,pred)==0.5

Kết quả

pred: [1, 0, 1, 0]
Confusion [TN FP; FN TP]: [[1, 1], [1, 1]]
Precision: 0.5
Recall: 0.5
F1: 0.5
ROC AUC: 0.75

Binary F1, macro F1 và weighted F1 không thay thế tùy tiện cho nhau.
