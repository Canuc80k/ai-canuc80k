BUỔI 1.9 — Đạo hàm và gradient descent

HỌC SINH CẦN HIỂU
- Đạo hàm là độ dốc; gradient gom độ dốc của nhiều tham số.
- Gradient descent đi ngược gradient với độ dài bước do learning rate quyết định.
- Loss là thứ optimizer tối ưu; metric đánh giá có thể khác loss.

CÂU HỎI MỞ BÀI
Ta nên bước sang trái hay sang phải để giảm loss?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
w_new = w_old - learning_rate × gradient

CẦN PHÂN BIỆT
Learning rate quá lớn có thể làm loss tăng hoặc dao động.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Tính dy/dx với y=x^2+3x tại từng x.
Input:
{
  "x": [
    2,
    0,
    -1
  ]
}
Output để đối chiếu sau khi làm:
[
  7,
  3,
  1
]

Bài trên lớp 2: Cập nhật w←w-lr*2*(w-target) đúng steps lần. Trả w cuối.
Input:
{
  "w": 0,
  "target": 3,
  "lr": 0.1,
  "steps": 5
}
Output để đối chiếu sau khi làm:
2.0169599999999996

BÀI VỀ NHÀ
- BTVN 1: Tính dy/dx với y=x^2+3x tại từng x.; xem BTVN_01.txt.
- BTVN 2: Cập nhật w←w-lr*2*(w-target) đúng steps lần. Trả w cuối.; xem BTVN_02.txt.
- BTVN 3: Với loss=(w*x+b-y)^2, trả grad_w và grad_b.; xem BTVN_03.txt.
