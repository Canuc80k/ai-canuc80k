BUỔI 1.3 — Chia dữ liệu và cross-validation

HỌC SINH CẦN HIỂU
- Train học tham số; validation chọn cấu hình; test đánh giá cuối.
- Stratified giữ tỉ lệ lớp; group split giữ đối tượng độc lập.
- Time split mô phỏng dự đoán tương lai; CV lặp protocol hợp lý qua folds.

CÂU HỎI MỞ BÀI
Ảnh cùng con vật vào cả train và valid có công bằng không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
groups_train ∩ groups_valid = ∅

CẦN PHÂN BIỆT
Không shuffle thời gian khi task yêu cầu dự đoán tương lai.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Trả các group có mặt trong cả train và valid, sorted tăng.
Input:
{
  "train_groups": [
    1,
    1,
    2
  ],
  "valid_groups": [
    2,
    3
  ]
}
Output để đối chiếu sau khi làm:
[
  2
]

Bài trên lớp 2: Tách indices theo time<=cutoff là train, còn lại valid. Giữ thứ tự input.
Input:
{
  "time": [
    5,
    1,
    8,
    3
  ],
  "cutoff": 3
}
Output để đối chiếu sau khi làm:
{
  "train": [
    1,
    3
  ],
  "valid": [
    0,
    2
  ]
}

BÀI VỀ NHÀ
- BTVN 1: Trả các group có mặt trong cả train và valid, sorted tăng.; xem BTVN_01.txt.
- BTVN 2: Tách indices theo time<=cutoff là train, còn lại valid. Giữ thứ tự input.; xem BTVN_02.txt.
- BTVN 3: Không shuffle; chia indices 0..n-1 thành k folds, fold đầu nhận phần dư. Trả list {train, valid}.; xem BTVN_03.txt.
