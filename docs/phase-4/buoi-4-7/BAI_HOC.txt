BUỔI 4.7 — Self-supervised vision

HỌC SINH CẦN HIỂU
- Self-supervised tạo mục tiêu từ dữ liệu; không đồng nhất supervised pretrained vớiSSL.
- Contrastive học views liên quan gần nhau, quản lý false negatives.
- DINOv2 làencoderSSL cósẵn; thực hành trích features đúng processor/checkpoint.

CÂU HỎI MỞ BÀI
Dữ liệu không nhãn tạo cặp positive/negative bằng cách nào?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
contrastive loss=-log softmax(similarity/temperature)[positive]

CẦN PHÂN BIỆT
Một loss nhỏ trên fixture không là kết quả huấn luyệnSSL ảnh thật.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Trả cosine của hai vector; có norm bằng 0 thì trả 0.
Input:
{
  "a": [
    1,
    0
  ],
  "b": [
    1,
    1
  ]
}
Output để đối chiếu sau khi làm:
0.7071067811865475

Bài trên lớp 2: Crossentropy chọnpositiveindex từsimilarity scores/temperature.
Input:
{
  "similarities": [
    1,
    0
  ],
  "temperature": 0.1,
  "positive": 0
}
Output để đối chiếu sau khi làm:
4.5398899217730104e-05
