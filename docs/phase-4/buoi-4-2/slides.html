Ý tưởng chính

Input(B,C,H,W) → logits(B,n_classes)

  • CNN tái dùng kernels theo vị trí, tận dụng cấu trúc không gian.
  • Conv→activation→pool→head; phải theo dõi shape qua từng layer.
  • Xem lỗi từng lớp/ảnh; train accuracy chỉ giúp debug loop.

Code minh họa (1)

import torch
from torch import nn
from sklearn.datasets import load_digits
torch.manual_seed(42)
torch.set_num_threads(1)

digits=load_digits();
X=torch.tensor(digits.images[:200]/16,dtype=torch.float32).unsqueeze(1)
y=torch.tensor(digits.target[:200],dtype=torch.long)
model=nn.Sequential(nn.Conv2d(1,8,3,padding=1),nn.ReLU(),nn.MaxPool2d(2),
                    nn.Flatten(),nn.Linear(8*4*4,10))
optimizer=torch.optim.Adam(model.parameters(),lr=.02)
for step in range(20):
    optimizer.zero_grad(); logits=model(X)
    loss=nn.CrossEntropyLoss()(logits,y); loss.backward(); optimizer.step()
