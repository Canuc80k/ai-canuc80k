THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Đếm số điểm đạt ngưỡng và tính trung bình tất cả điểm.
Input:
{
  "scores": [
    8,
    5,
    9,
    4
  ],
  "threshold": 6
}
Output để đối chiếu sau khi làm:
{
  "passed": 2,
  "mean": 6.5
}

Bài trên lớp 2: Gán nhãn: score>=8 là Tot; 6.5<=score<8 là Dat; còn lại Can_co_gang.
Input:
{
  "scores": [
    8,
    6.5,
    6.49,
    10
  ]
}
Output để đối chiếu sau khi làm:
[
  "Tot",
  "Dat",
  "Can_co_gang",
  "Tot"
]
