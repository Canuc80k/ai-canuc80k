BUỔI 0.5 — Matplotlib và Seaborn

HỌC SINH CẦN HIỂU
- Bar chart so sánh categories; histogram đếm giá trị trong khoảng.
- Scatter xem quan hệ hai biến số; line cần thứ tự như thời gian.
- Nhãn trục và đơn vị giúp đọc đúng; không cắt trục để tạo kết luận sai.

CÂU HỎI MỞ BÀI
Biểu đồ điểm từng người có trả lời phân bố điểm của lớp không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
bin_count = số mẫu thuộc khoảng đã công bố

CẦN PHÂN BIỆT
Một hình đẹp chưa trả lời câu hỏi nếu không nêu điều đang so sánh.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Đếm mỗi bin [edge_i, edge_i+1), riêng bin cuối bao gồm edge cuối. Values nằm trong toàn khoảng.
Input:
{
  "values": [
    0,
    5,
    7,
    9,
    10
  ],
  "edges": [
    0,
    5,
    7,
    9,
    10
  ]
}
Output để đối chiếu sau khi làm:
[
  1,
  1,
  1,
  2
]

Bài trên lớp 2: Trả loại biểu đồ: compare_categories→bar; distribution→histogram; two_numeric→scatter; sequence_over_time→line.
Input:
{
  "questions": [
    "compare_categories",
    "distribution",
    "two_numeric",
    "sequence_over_time"
  ]
}
Output để đối chiếu sau khi làm:
[
  "bar",
  "histogram",
  "scatter",
  "line"
]

BÀI VỀ NHÀ
- BTVN 1: Đếm mỗi bin [edge_i, edge_i+1), riêng bin cuối bao gồm edge cuối. Values nằm trong toàn khoảng.; xem BTVN_01.txt.
- BTVN 2: Trả loại biểu đồ: compare_categories→bar; distribution→histogram; two_numeric→scatter; sequence_over_time→line.; xem BTVN_02.txt.
- BTVN 3: Tính mean theo group; group được chuyển thành chuỗi trong keys output.; xem BTVN_03.txt.
