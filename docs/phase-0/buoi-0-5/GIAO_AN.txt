GIÁO ÁN BUỔI 0.5 — Matplotlib và Seaborn

TRÌNH TỰ DẠY
1. Hỏi: Biểu đồ điểm từng người có trả lời phân bố điểm của lớp không?
2. Cho học sinh đọc input và tự dự đoán output; chưa chạy code ngay.
3. Giải thích:
- Bar chart so sánh categories; histogram đếm giá trị trong khoảng.
- Scatter xem quan hệ hai biến số; line cần thứ tự như thời gian.
- Nhãn trục và đơn vị giúp đọc đúng; không cắt trục để tạo kết luận sai.
4. Chạy code từng đoạn; giữ file/outputs đã chạy để đối chiếu.
5. Làm hai bài trên lớp theo BAI_HOC.txt, chữa cả cases biên trong đề.
6. Giao đúng3BTVN; cho học sinh mở từng statement và sample trước khi về.

DẤU HIỆU HIỂU SAI CẦN HỎI LẠI
Một hình đẹp chưa trả lời câu hỏi nếu không nêu điều đang so sánh.

CÂU HỎI CHỐT
Vẽ cùng dữ liệu bằng bar và histogram; viết mỗi hình trả lời câu hỏi gì.

GHI CHÚ TÀI NGUYÊN
Code minh họa nhỏ đã chạy CPU. Các tệp pretrained thực hành bổ sung cần checkpoint/thư viện trong README. Không gọi fixture/weights=None là model pretrained đã kiểm chất lượng.

BTVN
