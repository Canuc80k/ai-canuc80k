Điểm thiếu của một học sinh nên lấy median của lớp nào?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • DataFrame có tên cột và kiểu dữ liệu; kiểm schema trước xử lý.
  • groupby gom cùng lớp; transform trả một giá trị cho mỗi dòng ban đầu.
  • merge theo khóa có kiểm tra cardinality tránh tăng số mẫu.

missing_score → median của group tương ứng

Code minh họa

import pandas as pd
# Bốn học sinh là fixture minh họa, không phải hồ sơ cá nhân.
students = pd.DataFrame({"id":[1,2,3,4], "class":["A","A","B","B"],
                         "score":[8.0,None,6.0,10.0]})
teachers = pd.DataFrame({"class":["A","B"], "teacher":["Mai","Son"]})
# transform trả một median cho từng dòng thuộc đúng nhóm.
median = students.groupby("class")["score"].transform("median")
students["score"] = students["score"].fillna(median)
# validate ngăn merge làm tăng số dòng do khóa trùng.
full = students.merge(teachers, on="class", validate="many_to_one")
print(full.to_string(index=False))
print("Điểm trung bình mỗi lớp:")
print(full.groupby("class")["score"].mean().to_string())
assert len(full) == 4 and full["score"].notna().all()

Bài trên lớp

Bài 1

Tính mean theo group; group được chuyển thành chuỗi trong keys output.

{
  "groups": [
    "A",
    "A",
    "B"
  ],
  "values": [
    8,
    6,
    10
  ]
}
Đáp án
{
  "A": 7.0,
  "B": 10.0
}

Bài 2

Học median từ các giá trị train không null; điền null trong query. Nếu train toàn null dùng 0.

{
  "train": [
    10,
    null,
    30
  ],
  "query": [
    null,
    100
  ]
}
Đáp án
[
  20.0,
  100
]
