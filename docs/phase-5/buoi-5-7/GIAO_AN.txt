GIÁO ÁN BUỔI 5.7 — Pretrained LMs, prompting và VLM

TRÌNH TỰ DẠY
1. Hỏi: Một câu trả lời đúng ý nhưng sai schema có nộp được không?
2. Cho học sinh đọc input và tự dự đoán output; chưa chạy code ngay.
3. Giải thích:
- Prompt quy định task/context/output; source và model version cầnrõ.
- Validate structuredoutput, labelmap vàgrounding; VLM có thêm image inputs.
- API được đề cấp mới dùng; syllabus nêuAPI không cấp phép dùng ởmọikỳthi.
4. Chạy code từng đoạn; giữ file/outputs đã chạy để đối chiếu.
5. Làm hai bài trên lớp theo BAI_HOC.txt, chữa cả cases biên trong đề.
6. Giao đúng3BTVN; cho học sinh mở từng statement và sample trước khi về.
