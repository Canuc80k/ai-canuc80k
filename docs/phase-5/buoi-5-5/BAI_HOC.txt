BUỔI 5.5 — Language modeling

HỌC SINH CẦN HIỂU
- Causal LM dự đoán token tiếp theo từ con text trước.
- Loss cần shift targets vàcausalmask; tokenization là phần của đánh giá.
- Perplexity=exp(meanNLL); không so trực tiếp khi tokenizer khác.

CÂU HỎI MỞ BÀI
Target next-token có cùng vị trí với input token không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
