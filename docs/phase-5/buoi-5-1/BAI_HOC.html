Buổi 5.1: Text processing và baseline NLP

Máy biến một câu thành features mà không đọc nghĩa như người ra sao?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • Tokenization/vocabulary biến text thành indices/đếm; TF-IDF weighted features.
  • Sparse baseline thường nhanh và cần fit vocab trên train.
  • Giữ Unicode/negation; tránh duplicate qua split.

TF-IDF dùng term frequency và inverse document frequency

Code minh họa

from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
texts=["rain floods city","storm damages bridge","team wins match", "player scores goal"]
y=[1,1,0,0]  # Fixture: 1 thời tiết, 0 thể thao.
model=make_pipeline(TfidfVectorizer(),LogisticRegression(random_state=42))
model.fit(texts,y)
print("Vocabulary:",sorted(model[0].vocabulary_))
query=["rain storm","team player"]
print("Labels:",model.predict(query).tolist())
print("Probs:",model.predict_proba(query).round(4).tolist())
assert model.predict(query).tolist()==[1,0]
# Fit vocabulary/IDF chỉ trên train; fixture ít câu chỉ để đọc thao tác.

Kết quả

Vocabulary: ['bridge', 'city', 'damages', 'floods', 'goal', 'match', 'player', 'rain', 'scores', 'storm', 'team', 'wins']
Labels: [1, 0]
Probs: [[0.4189, 0.5811], [0.5811, 0.4189]]

Không fit IDF/vocabulary trên cảlabeled test rồi báo validation độc lập.
