BUỔI 5.6 — Encoder-decoder và text generation

HỌC SINH CẦN HIỂU
- Encoder tạo biểu diễn source; decoder sinh target autoregressive.
- Teacher forcing cấp target trước đó khi train; inference dùng token đã sinh.
- BOS/EOS, mask, decoding và metric phải định nghĩa theo task.

CÂU HỎI MỞ BÀI
Encoder đọc source, decoder nhìn những gì ở training và inference?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
decoder_input=[BOS]+target; labels=target+[EOS]

CẦN PHÂN BIỆT
Không cấp target tươnglai qua mask sai; toyshift không thay bài dịch thật.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Decoderinput=[BOS]+translation, target=translation+[EOS].
Input:
{
  "translation": [
    "hello",
    "there"
  ],
  "bos": "BOS",
  "eos": "EOS"
}
Output để đối chiếu sau khi làm:
{
  "input": [
    "BOS",
    "hello",
    "there"
  ],
  "target": [
    "hello",
    "there",
    "EOS"
  ]
}

Bài trên lớp 2: LxL boolean; rowiđượcnhìnkeyj khi j<=i.
Input:
{
  "length": 3
}
Output để đối chiếu sau khi làm:
[
  [
    true,
    false,
    false
  ],
  [
    true,
    true,
    false
  ],
  [
    true,
    true,
    true
  ]
]
