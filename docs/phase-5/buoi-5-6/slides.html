Buổi 5.6: Encoder-decoder và text generation

Encoder đọc source, decoder nhìn những gì ở training và inference?

Buổi 5.6

Ý tưởng chính

decoder_input=[BOS]+target; labels=target+[EOS]

  • Encoder tạo biểu diễn source; decoder sinh target autoregressive.
  • Teacher forcing cấp target trước đó khi train; inference dùng token đã sinh.
  • BOS/EOS, mask, decoding và metric phải định nghĩa theo task.
Buổi 5.6

Ví dụ

{
  "translation": [
    "hello",
    "there"
  ],
  "bos": "BOS",
  "eos": "EOS"
}
Buổi 5.6

Đáp án ví dụ

{
  "input": [
    "BOS",
    "hello",
    "there"
  ],
  "target": [
    "hello",
    "there",
    "EOS"
  ]
}
Buổi 5.6

Code minh họa

# Decoder input và target lệch một vị trí; source là một chuỗi khác.
source=["xin","chào"]
translation=["hello","there"]
decoder_input=["BOS"]+translation
decoder_target=translation+["EOS"]
print("Encoder source:",source)
print("Decoder input:",decoder_input)
print("Decoder target:",decoder_target)
# Decoder chỉ thấy các target tokens trước đó ở training (teacher forcing).
for step,(previous,wanted) in enumerate(zip(decoder_input,decoder_target)):
    print("step",step,"previous",previous,"wanted",wanted)
assert len(decoder_input)==len(decoder_target)
