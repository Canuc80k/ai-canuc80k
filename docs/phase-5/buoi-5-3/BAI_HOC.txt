THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Mask bằng 1 nếu token!=pad_id; bằng 0 nếu là padding.
Input:
{
  "ids": [
    [
      1,
      2,
      0
    ],
    [
      3,
      0,
      0
    ]
  ],
  "pad_id": 0
}
Output để đối chiếu sau khi làm:
[
  [
    1,
    1,
    0
  ],
  [
    1,
    0,
    0
  ]
]

Bài trên lớp 2: Mean token vectors chỉ tại mask=1; nếu toàn 0 trả zero vector.
Input:
{
  "tokens": [
    [
      1,
      0
    ],
    [
      0,
      1
    ],
    [
      9,
      9
    ]
  ],
  "mask": [
    1,
    1,
    0
  ]
}
Output để đối chiếu sau khi làm:
[
  0.5,
  0.5
]
