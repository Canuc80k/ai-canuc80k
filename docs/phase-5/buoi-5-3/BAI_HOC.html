Buổi 5.3: BERT và pretrained text encoders

Tokenizer khác checkpoint có thể dùng cùng token IDs không?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • BERT pretrained encoder cần đúng tokenizer, attentionmask và head.
  • Frozen features khác fine-tune; labelmap thuộcdata/task.
  • Padding/truncation ảnh hưởng information; không nhầm hidden states với logits.

IDs→embedding→encoder→pooling/head→logits

Code minh họa

import torch
from torch import nn
torch.manual_seed(42)
torch.set_num_threads(1)
# Tiny Transformer encoder minh họa head/mask; KHÔNG giả là BERT pretrained.
embedding=nn.Embedding(8,4,padding_idx=0)
layer=nn.TransformerEncoderLayer(4,2,8,dropout=0,batch_first=True)
classifier=nn.Linear(4,2)
ids=torch.tensor([[1,2,0],[3,4,5]])
pad=(ids==0)
hidden=layer(embedding(ids),src_key_padding_mask=pad)
mask=(~pad).unsqueeze(-1)
pooled=(hidden*mask).sum(1)/mask.sum(1)
logits=classifier(pooled)
print("IDs shape:",tuple(ids.shape),"padding mask:",pad.tolist())
print("Hidden:",tuple(hidden.shape),"logits:",tuple(logits.shape))
assert tuple(logits.shape)==(2,2)
# BERT thật: tokenizer và checkpoint phải khớp; bert_demo.py có code inference cache-only.

Kết quả

IDs shape: (2, 3) padding mask: [[False, False, True], [False, False, False]]
Hidden: (2, 3, 4) logits: (2, 2)

TinyTransformer demo có weights ngẫu nhiên, không phải BERT pretrained.

transformers + local BERT checkpoint/tokenizer. Chạy khi có checkpoint/thư viện đã cấp; không đồng nhất với fixture nhỏ ở trên.
