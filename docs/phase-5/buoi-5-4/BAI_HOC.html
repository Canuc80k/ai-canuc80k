Buổi 5.4: Sequence labeling và phân tách từ

Một ranh giới đúng ký tự đã chắc đúng cả từ con chưa?

Bộ slide PowerPoint · Trình chiếu trong trình duyệt · Notebook · Python

Kiến thức

  • Sequence labeling giữ alignment từng token/ký tự.
  • Span bắt đầu/kết thúc phải đúng; boundary-F1 khác word-span F1.
  • Indices theo Unicode code points của đề, không theo byte UTF8.

span=[start,end), end không thuộc span

Code minh họa

# Ký tự cuối mỗi từ con được đánh dấu 1; indices theo ký tự Unicode.
word="rainbow"; labels=[0,0,0,1,0,0,1]
def spans(word,labels):
    if len(word)!=len(labels) or not labels or labels[-1]!=1:
        raise ValueError("Sai chiều dài hoặc thiếu ranh giới cuối")
    start=0; result=[]
    for end,label in enumerate(labels):
        if label==1: result.append((start,end+1,word[start:end+1])); start=end+1
    return result
print("Spans:",spans(word,labels))
print("Số ký tự tiếng Việt:",len("học"),"số bytes UTF8:",len("học".encode("utf-8")))
assert [s[2] for s in spans(word,labels)]==["rain","bow"]

Kết quả

Spans: [(0, 4, 'rain'), (4, 7, 'bow')]
Số ký tự tiếng Việt: 3 số bytes UTF8: 5

len(text.encode()) khác len(text); phải kiểm nhãn cuối và độ dài.
