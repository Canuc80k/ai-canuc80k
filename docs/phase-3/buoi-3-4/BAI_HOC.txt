BUỔI 3.4 — Activation, loss và output head

HỌC SINH CẦN HIỂU
- Binary/multiclass/regression cần output head, target dtype và loss tương ứng.
- CrossEntropyLoss nhận logits; BCEWithLogitsLoss kết hợp sigmoid/log-loss ổn định.
- Softmax cần trừ max để tránh exp overflow.

CÂU HỎI MỞ BÀI
Head trả một logit hay một vector classes?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
softmax_i = exp(z_i-max(z))/sum_j exp(z_j-max(z))

CẦN PHÂN BIỆT
Đưa probability vào một loss chờ logits là lỗi hợp đồng.
