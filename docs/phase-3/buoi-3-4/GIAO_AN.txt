GIÁO ÁN BUỔI 3.4 — Activation, loss và output head

TRÌNH TỰ DẠY
1. Hỏi: Head trả một logit hay một vector classes?
2. Cho học sinh đọc input và tự dự đoán output; chưa chạy code ngay.
3. Giải thích:
- Binary/multiclass/regression cần output head, target dtype và loss tương ứng.
- CrossEntropyLoss nhận logits; BCEWithLogitsLoss kết hợp sigmoid/log-loss ổn định.
- Softmax cần trừ max để tránh exp overflow.
4. Chạy code từng đoạn; giữ file/outputs đã chạy để đối chiếu.
5. Làm hai bài trên lớp theo BAI_HOC.txt, chữa cả cases biên trong đề.
6. Giao đúng3BTVN; cho học sinh mở từng statement và sample trước khi về.

DẤU HIỆU HIỂU SAI CẦN HỎI LẠI
Đưa probability vào một loss chờ logits là lỗi hợp đồng.

CÂU HỎI CHỐT
Giải thích vì sao logits1000,1001 vẫn tạo probability hữu hạn.
