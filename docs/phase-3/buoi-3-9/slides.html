Nếu không có nhãn, autoencoder học mục tiêu nào?

Buổi 3.9

Ý tưởng chính

loss = mean((reconstruction-input)²)

  • Encoder nén input; decoder tái tạo input từ latent.
  • Reconstruction loss dùng chính input làm mục tiêu; không phải class accuracy.
  • Bottleneck/denoising giúp học biểu diễn; VAE thêm mô hình hóa distribution.
Buổi 3.9
