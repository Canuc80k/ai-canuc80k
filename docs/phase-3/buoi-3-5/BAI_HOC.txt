THỰC HÀNH TRÊN LỚP

  ],

    1
  ]
}

1.4

Input:
{
  "w": [
    1,
    2
  ],
  "grad": [
    2,
    -1
  ],
  "lr": 0.1
}
Output để đối chiếu sau khi làm:
[
  0.8,
  2.1
]
