BUỔI 3.8 — Embeddings, pooling, attention và Transformers

HỌC SINH CẦN HIỂU
- Embeddings biến IDs thành vectors; pooling phải bỏ padding.
- Q/K xác định weights; V là nội dung được tổng hợp; softmax theo keys.
- Transformer thêm multi-head, FFN, residual, normalization và thông tin vị trí.

CÂU HỎI MỞ BÀI
Padding hoặc token tương lai có được tham gia attention không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
Attention(Q,K,V)=softmax(QKᵀ/sqrt(dk)+mask)V

CẦN PHÂN BIỆT
Padding mask và causal mask khác nhau; row bị mask hết có thể NaN.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Mean token vectors chỉ tại mask=1; nếu toàn 0 trả zero vector.
Input:
{
  "tokens": [
    [
      1,
      0
    ],
    [
      0,
      1
    ],
    [
      9,
      9
    ]
  ],
  "mask": [
    1,
    1,
    0
  ]
}
Output để đối chiếu sau khi làm:
[
  0.5,
  0.5
]

Bài trên lớp 2: Scaled-dot attention QK^T/sqrt(dk), softmax theo keys; allow=false bịmask. Mỗi query có ít nhất 1 key được phép.
Input:
{
  "q": [
    [
      1,
      0
    ]
  ],
  "k": [
    [
      1,
      0
    ],
    [
      0,
      1
    ]
  ],
  "v": [
    [
      10,
      0
    ],
    [
      0,
      20
    ]
  ],
  "allow": [
    [
      true,
      false
    ]
  ]
}
Output để đối chiếu sau khi làm:
[
  [
    10.0,
    0.0
  ]
]
