BUỔI 3.10 — Fine-tuning đầy đủ và PEFT

HỌC SINH CẦN HIỂU
- Full fine-tune cập nhật base; frozen probe chỉ cập nhật head.
- LoRA học update low-rank; adapter phải lưu cùng đúng base revision.
- Đếm trainable params, đo validation và inference cost khi so phương án.

CÂU HỎI MỞ BÀI
Có cần cập nhật tất cả weights của pretrained model không?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
ΔW=B×A, params=r(in+out)

CẦN PHÂN BIỆT
Adapter nhỏ không đồng nghĩa mọi chi phí inference đều nhỏ hơn.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Tổng số parameters trainable của các layers được đánh trainable=true.
Input:
{
  "layers": [
    {
      "name": "base",
      "count": 16,
      "trainable": false
    },
    {
      "name": "head",
      "count": 9,
      "trainable": true
    }
  ]
}
Output để đối chiếu sau khi làm:
9

Bài trên lớp 2: Adapter A: r x in, B: out x r; trả adapter params và base params(out*in).
Input:
{
  "in": 4,
  "out": 4,
  "r": 2
}
Output để đối chiếu sau khi làm:
{
  "adapter": 16,
  "base": 16
}
