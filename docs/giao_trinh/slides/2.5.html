Đối chiếu trên máy

Bốn điểm 1, 2, 3, 4 với nhãn 0, 0, 1, 1 của ví dụ tính tay.

best = None
for threshold in [1.5, 2.5, 3.5]:
    left = x_small <= threshold
    right = ~left
    after = (
        left.mean() * gini(y_small[left])
        + right.mean() * gini(y_small[right])
    )
    gain = gini(y_small) - after
    if best is None or gain > best[0]:
        best = (gain, threshold)
print("ngưỡng:", best[1])

Lỗi train 0 nghĩa là cả hai trả đúng nhãn cho mọi mẫu của DDD, nên dự đoán trên DDD trùng nhau. Gốc, độ sâu và các feature được dùng thì có thể khác.
