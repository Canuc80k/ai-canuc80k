image và kernel đã được tạo ở ví dụ tính tay; hàm dưới chỉ đọc các cửa sổ nằm trọn trong ảnh (không padding).

Không lật kernel: đây là cross-correlation, cũng là quy ước của Conv2d trong bài.

def correlate_valid(image, kernel):
    height, width = image.shape
    kh, kw = kernel.shape
    result = np.zeros((height - kh + 1, width - kw + 1))
    for row in range(result.shape[0]):
        for col in range(result.shape[1]):
            window = image[row:row + kh, col:col + kw]
            result[row, col] = np.sum(window * kernel)
    return result

Theo dõi hai số

rrr: số ô input trong vùng nhìn; jjj: khoảng cách trên input giữa hai vị trí output kề nhau. Bắt đầu r=j=1r=j=1r=j=1.

rmới=r+(k−1)d j,jmới=s jr_{\mathrm{mới}}=r+(k-1)d\,j,\qquad j_{\mathrm{mới}}=s\,jrmới​=r+(k−1)dj,jmới​=sj

Conv 3, stride 1: r=3r=3r=3, j=1j=1j=1. Pool 2, stride 2: r=4r=4r=4, j=2j=2j=2. Conv 3, stride 1: r=8r=8r=8, j=2j=2j=2; cả ba lớp dùng dilation 1.
