# Hướng dẫn học

## Website

- **Lộ trình:** 4 khóa, mỗi khóa gồm các phase, mỗi phase gồm các bài.
- **Một bài:** Bài học, Slide, Code, Bài tập.
- **Tìm kiếm:** gõ có dấu hoặc không dấu; phím `/` để tìm nhanh.
- **Tiến độ:** lưu trong trình duyệt của máy đang dùng.

## Colab và Kaggle

1. Tải notebook ở mục Code.
2. Mở bằng Colab (File → Upload notebook) hoặc Kaggle (Create → Notebook → Import).
3. Bật GPU T4: Colab — Runtime → Change runtime type; Kaggle — Settings → Accelerator.
4. Tải dữ liệu đi kèm và sửa đường dẫn ở ô đầu notebook.
5. Chạy lại toàn bộ notebook từ đầu trước khi nộp.

## Làm bài tập

1. Đọc đề: dữ liệu vào, kết quả ra, metric, định dạng nộp.
2. Làm baseline, ghi điểm validation.
3. Cải tiến từng bước, ghi lại thay đổi và điểm.
4. Chỉ dùng tập test để nộp cuối.
