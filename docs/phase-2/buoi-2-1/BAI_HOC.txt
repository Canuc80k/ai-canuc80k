BUỔI 2.1 — Linear Regression

HỌC SINH CẦN HIỂU
- Linear Regression tìm weights/bias làm squared residual nhỏ.
- Hệ số biểu diễn quan hệ trong dữ liệu; không tự chứng minh nhân quả.
- So với mean baseline và xem residual trên validation.

CÂU HỎI MỞ BÀI
Một đường thẳng có thể dự đoán ngoài các điểm đã thấy thế nào?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
ŷ = w·x+b

CẦN PHÂN BIỆT
Không dự đoán lớn hơn thật chỉ vì R2 trên train đẹp.

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Dự đoán từng hàng dot(row, w)+b.
Input:
{
  "X": [
    [
      0
    ],
    [
      1
    ],
    [
      2
    ]
  ],
  "w": [
    2
  ],
  "b": 1
}
Output để đối chiếu sau khi làm:
[
  1,
  3,
  5
]

Bài trên lớp 2: Fit y=w*x+b bằng least squares; nếu x toàn hằng thì w=0, b=mean(y).
Input:
{
  "x": [
    0,
    1,
    2,
    3
  ],
  "y": [
    1,
    3,
    5,
    7
  ]
}
Output để đối chiếu sau khi làm:
{
  "w": 2.0,
  "b": 1.0
}

BÀI VỀ NHÀ
- BTVN 1: Dự đoán từng hàng dot(row, w)+b.; xem BTVN_01.txt.
- BTVN 2: Fit y=w*x+b bằng least squares; nếu x toàn hằng thì w=0, b=mean(y).; xem BTVN_02.txt.
- BTVN 3: Hồi quy quan hệ tuyến tính; xem BTVN_03.txt.
