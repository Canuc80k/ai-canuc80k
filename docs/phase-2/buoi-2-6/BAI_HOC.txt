BUỔI 2.6 — Bagging, Random Forest và boosting

HỌC SINH CẦN HIỂU
- Bagging học các model trên các mẫu biến đổi, giúp giảm phương sai.
- Random Forest thêm ngẫu nhiên khi chọn features; averaging giảm dao động.
- Boosting thêm model để sửa lỗi theo objective; cần quản lý capacity/số vòng.

CÂU HỎI MỞ BÀI
Nhiều model sửa được những loại lỗi khác nhau thế nào?

VÍ DỤ VÀ CODE

THỰC HÀNH TRÊN LỚP

Bài trên lớp 1: Trung bình probabilities từ các models cho từng sample.
Input:

    [
      [
        0.8,
        0.2
      ],
      [
        0.1,
        0.9
      ]
    ],
    [
      [
        0.4,
        0.6
      ],
      [
        0.3,
        0.7
      ]
    ]
  ]
}
Output để đối chiếu sau khi làm:
[
  [
    0.6000000000000001,
    0.4
  ],
  [
    0.2,
    0.8
  ]
]

Bài trên lớp 2: Cập nhật prediction + learning_rate*weak_prediction cho từng mẫu.
Input:
{

  ],
  "weak": [
    1,
    1
  ],

}
Output để đối chiếu sau khi làm:
[
  2.5,
  4.5
]
