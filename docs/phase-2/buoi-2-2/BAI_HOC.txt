BUỔI 2.2 — Logistic Regression và Softmax

HỌC SINH CẦN HIỂU
- Sigmoid cho binary probability; softmax tạo phân bố qua nhiều classes.
- Logit là số trước activation; probability sau activation.
- Decision threshold là lựa chọn sau khi học, theo metric/chi phí.

CÂU HỎI MỞ BÀI
Một số bất kỳ từ linear layer chuyển thành probability ra sao?

VÍ DỤ VÀ CODE
Chạy python -X utf8 code_minh_hoa.py trong thư mục buổi. Notebook code_minh_hoa.ipynb có code và output đã chạy.
sigmoid(z)=1/(1+exp(-z))

CẦN PHÂN BIỆT
predict_proba cột1 phải khớp label trong classes_, không đoán ý nghĩa từ vị trí.

THỰC HÀNH TRÊN LỚP

    1000,
    -1000
  ]
}

  0.75,
  1.0,
  0.0
]
